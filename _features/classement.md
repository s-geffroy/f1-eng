## The great technical lineages

This table shows **intellectual lineages**, not master–pupil relationships. What links each step, and on what sources, is on the [lineages page]({{ site.baseurl }}/en/lineages/).

| Branch | Lineage |
|---|---|
| Architecture | Cooper → Chapman → Barnard |
| Aerodynamics | Chapman/Wright → Newey |
| Engine | Duckworth → Cowell |
| Digital and control | Dernie → Lowe → McLaren simulator (1996) |
| Systems organisation | Head → Brawn → 2014 Mercedes programme |

## Three ways to be at the top

- **Chapman**: multiple breakthroughs, through an accumulation of radical architectural changes.
- **Barnard**: probably the clearest authorship, with two direct innovations that became universal.
- **Newey**: the most durable adaptation, with championship-winning cars at Williams, McLaren and Red Bull, across several generations of regulations.

This ranking is not a one-dimensional scale of "genius". It ranks **historical capacities to shift the technical frontier of Formula 1**.

> Revolutionising F1 is not just about building the fastest car: it is about forcing others to change the way they build an F1 car.
